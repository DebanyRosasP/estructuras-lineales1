Bienvenidos

La protección y seguridad en los sistemas operativos es fundamental para mantener la información segura, evitar accesos no autorizados y garantizar el correcto funcionamiento de una computadora. En esta página conoceremos los conceptos, funciones y métodos más importantes relacionados con la seguridad informática.

6.1. Concepto y objetivos de protección y seguridad

La protección y seguridad son mecanismos que utilizan los sistemas operativos para cuidar los recursos de una computadora y evitar que personas o programas no autorizados accedan a la información.

Objetivos principales:

  • Evitar el acceso no autorizado a los archivos.
  • Proteger la información personal y confidencial.
  • Garantizar que los recursos se utilicen correctamente.
  • Prevenir daños y pérdidas de información.
  • Mantener la disponibilidad de los servicios.
Ejemplo: Cuando una computadora solicita una contraseña para ingresar a una cuenta, está utilizando un mecanismo de protección.

6.2. Clasificación aplicada a la seguridad

La seguridad informática se puede clasificar de acuerdo con los elementos que busca proteger y los mecanismos que utiliza.

Principales tipos:

  • Seguridad física: Protege los equipos y dispositivos contra robos, daños o accidentes.
  • Seguridad lógica: Protege los programas, archivos y sistemas mediante contraseñas y permisos.
  • Seguridad de red: Protege las conexiones y los datos que se transmiten por internet.
  • Seguridad de la información: Busca mantener la confidencialidad, integridad y disponibilidad de los datos.
Ejemplo: Un antivirus protege el sistema contra programas maliciosos, mientras que una cerradura protege físicamente un equipo o una instalación.

6.3. Funciones del sistema de protección

El sistema de protección se encarga de controlar cómo los usuarios y programas utilizan los recursos de una computadora.

Funciones principales:

  • Controlar el acceso de los usuarios.
  • Asignar permisos para leer, modificar o eliminar archivos.
  • Identificar a los usuarios del sistema.
  • Evitar que los programas interfieran entre sí.
  • Supervisar el uso de los recursos.
  • Registrar actividades importantes para detectar problemas.
Ejemplo: En una computadora escolar, un alumno puede tener permiso para abrir documentos, pero no para modificar la configuración del sistema.

6.4. Implantación de matrices de acceso

Una matriz de acceso es una herramienta utilizada para representar los permisos que tienen los usuarios sobre diferentes recursos de un sistema.

Elementos de una matriz:

  • Usuarios: Personas que utilizan el sistema.
  • Objetos: Archivos, carpetas o dispositivos.
  • Permisos: Acciones que pueden realizarse sobre los objetos.

Ejemplo de matriz de acceso:

Usuario Leer Escribir Eliminar
Administrador ✓ ✓ ✓
Profesor ✓ ✓ ✗
Alumno ✓ ✗ ✗
Ejemplo: Un administrador puede modificar y eliminar archivos, mientras que un alumno solamente puede consultarlos.

6.5. Protección basada en el lenguaje

La protección basada en el lenguaje utiliza las características de los lenguajes de programación para controlar el acceso a los datos y evitar operaciones no permitidas.

Características:

  • Controla el acceso a las variables y datos.
  • Permite establecer niveles de visibilidad.
  • Ayuda a evitar modificaciones no autorizadas.
  • Organiza el acceso a las funciones y componentes.

Ejemplo en programación:

En Java o C++, las palabras clave como private, public y protected permiten controlar la visibilidad de los elementos de una clase.

Ejemplo: Un atributo privado solamente puede ser utilizado directamente dentro de su propia clase.

6.6. Validación y amenazas al sistema

La validación es el proceso de comprobar que los usuarios, datos y operaciones cumplen con las reglas de seguridad establecidas por el sistema.

Tipos de validación:

  • Autenticación mediante contraseñas.
  • Verificación de identidad.
  • Comprobación de permisos.
  • Validación de los datos ingresados.

Principales amenazas:

  • Virus: Programas que pueden dañar archivos y sistemas.
  • Malware: Software diseñado para realizar actividades dañinas.
  • Phishing: Engaños que buscan obtener información personal.
  • Robo de contraseñas: Acceso a cuentas sin autorización.
  • Ransomware: Programa malicioso que bloquea o cifra información para exigir un pago.
Ejemplo: Un sistema que solicita una contraseña y verifica la identidad del usuario ayuda a evitar accesos no autorizados.

6.7. Cifrado

El cifrado es un procedimiento que transforma la información original en un formato que no puede entenderse fácilmente sin una clave o método de descifrado.

Tipos de cifrado:

  • Cifrado simétrico: Utiliza la misma clave para cifrar y descifrar la información.
  • Cifrado asimétrico: Utiliza dos claves relacionadas: una pública y otra privada.

¿Para qué sirve?

  • Proteger contraseñas y datos personales.
  • Mantener privadas las comunicaciones.
  • Evitar que terceros puedan leer información confidencial.
  • Proteger archivos y documentos importantes.
Ejemplo: Cuando ingresamos a una página bancaria que utiliza HTTPS, la conexión emplea cifrado para proteger la información que se transmite.

Conclusión

La protección y seguridad son elementos esenciales en los sistemas operativos, ya que permiten cuidar los datos, controlar los accesos y prevenir amenazas informáticas. Conocer herramientas como las matrices de acceso, la validación y el cifrado ayuda a comprender cómo se mantiene segura la información. Por eso, es importante utilizar buenas prácticas de seguridad y proteger nuestros dispositivos y datos personales.
